# Automatic_Night_Light

> Overview
- This project demonstrates a smart lighting system using an LDR (Light Dependent Resistor) sensor and an LED. The LED automatically turns ON when the surrounding light intensity drops below a certain threshold, and turns OFF when sufficient light is detected. This provides a hands-free, energy-efficient lighting solution.

> Features
- Automatic LED activation in darkness. 
- Adjustable sensitivity using Arduino analog input.
- Simple and reliable design suitable for home or small IoT applications.
- Energy-saving and convenient lighting control.

> Components Required
- Arduino Uno (or compatible board)
- LED
- LDR (Light Dependent Resistor)
- 220Ω Resistor (for LED)
- 10kΩ Resistor (for LDR voltage divider)
- Jumper wires and breadboard

> How It Works?
- LDR sensor measures ambient light intensity.
- Arduino reads the LDR values continuously.
- If light falls below a set threshold → LED turns ON.
- If light exceeds the threshold → LED turns OFF.
- Provides automatic, hands-free lighting based on darkness.

> Applications
- Night lamps or garden lights
- Automatic lighting in closets or rooms
- Energy-efficient IoT lighting solutions
